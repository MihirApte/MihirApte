## About me

I turn messy data into clear, usable answers. My work covers **NLP and generative AI**, **classical machine learning**, **physics-informed deep learning** and **data engineering and business intelligence**, from the first query to a deployed app or dashboard.

I like to formulate a problem from scratch, build a proper evaluation, and be honest about where a metric is hiding something important. Where I can, I ship each project with a demo, dashboard or walkthrough, so the results are not stuck in a notebook.

- Experience: data engineering, data science and software development, plus end to end personal and academic projects.

## Featured projects

### 1. Improving RAVE Video Editing (MSc dissertation)
Improved the temporal consistency of a published CVPR 2024 zero-shot video-editing model by replacing its random frame shuffling with CLIP similarity and K-means frame grouping, benchmarked on 21 test videos against 4 competing methods.<br/>
**Tech:** PyTorch, HuggingFace Diffusers, CLIP, ControlNet, OpenCV<br/>
**Links:** [GitHub repo](https://github.com/MihirApte/dissertation-mihir)

### 2. Comment Lab: AI content assistant for creators
A full-stack tool that turns YouTube comments into topics, sentiment and evidence-backed content ideas, shipped as a one-click Windows installer. Phase 1 (YouTube) is shipped and Phase 2 (Instagram) is in progress.<br/>
**Tech:** Python, FastAPI, BERTopic, UMAP, HDBSCAN, XLM-RoBERTa, Ollama<br/>
**Links:** [Live preview](https://mihirapte.github.io/comment-lab-preview/) (the source code is private while Phase 2 is in progress)

### 3. Cognitive Distortion Detector
Fine-tuned transformers that detect 10 cognitive distortions in free text, validated against a licensed psychologist's annotations. Phase 2 adds a hybrid LLM explanation layer with a citation check and safety guardrails (macro F1 0.17 to 0.27 against a DistilBERT baseline, 20 of 20 adversarial tests passing).<br/>
**Tech:** PyTorch, MentalRoBERTa, LIME, Groq API, FastAPI, Docker<br/>
**Links:** [Live app](https://huggingface.co/spaces/mihir-apte/cognitive-distortion-detector) | [GitHub repo](https://github.com/MihirApte/Cognitive-Distortion-Detector)

### 4. Mortgage Portfolio MI and Data Quality Dashboard
An end to end pipeline and 3-page Power BI dashboard on real Central Bank of Ireland arrears data (19,199 rows), with 23 data quality rules, 102 of 102 reconciliation steps matching and a documented source to dashboard lineage.<br/>
**Tech:** PostgreSQL, SQL, Python, Power BI, DAX<br/>
**Links:** [GitHub repo](https://github.com/MihirApte/mortgage-mi)

### 5. Customer Churn Business Simulator
An XGBoost churn model with a SHAP what-if simulator, tuned to real business costs. Phase 2 adds a RAG retention advisor that lifted retrieval precision from 84.0% to 97.5% and passed citation validation on 40 of 40 LLM plans.<br/>
**Tech:** XGBoost, SHAP, Sentence-Transformers, Groq API, Streamlit, pytest<br/>
**Links:** [Live app](https://huggingface.co/spaces/mihir-apte/CustomerChurnAnalyser) | [GitHub repo](https://github.com/MihirApte/Customer-Churn-Prediction)

### 6. Physics-Informed Neural Network for heat conduction
A neural network that solves heat-conduction PDEs with no labelled data, matching the analytical solution to within 0.0015 degrees C, extended to a 2D transient problem and cross-checked against a finite-difference solver built from scratch.<br/>
**Tech:** PyTorch, NumPy, Matplotlib, Jupyter<br/>
**Links:** [GitHub repo](https://github.com/MihirApte/pinn-heat-conduction)
